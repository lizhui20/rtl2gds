# 发布与脱敏检查表

虚拟机镜像公开前，需要完成技术和安全检查。仅压缩并上传文件不等于完成可靠发布。

## 安全与隐私

- [ ] 删除 SSH/GPG 私钥、云凭据、Git 凭据、API Token 和浏览器登录状态
- [ ] 清理 shell 历史、最近文件、剪贴板、下载目录、回收站和编辑器历史
- [ ] 删除个人姓名、邮箱、手机号、学号、工号、内网域名和 VPN 配置
- [ ] 清理 `/tmp`、`/var/tmp`、日志、崩溃转储和交换空间中的敏感内容
- [ ] 创建专用默认账号，不复用维护者个人密码
- [ ] 公布默认密码的同时强制或明确要求首次登录后修改
- [ ] 检查系统服务、开放端口、共享目录和自动挂载

## 可复现性

- [ ] 在全新宿主机上分别测试 OVF 导入和 VMX 打开
- [ ] 核验 `/etc/redhat-release` 与仓库名称一致
- [ ] 记录 VMware 产品和最低兼容版本
- [ ] 运行 `scripts/collect-environment.sh` 并人工脱敏
- [ ] 发布准确的工具、版本、PDK 和工作流矩阵
- [ ] 为所有发布文件生成 SHA-256 校验值
- [ ] 在 GitHub Release 中记录版本号、发布日期、变更和已知问题
- [ ] 至少由另一位使用者完成一次从下载到 `lmg` 启动的复测

## 体积与分发

- [ ] 关闭虚拟机后再打包，避免包含锁文件和运行中的不一致状态
- [ ] 删除可安全移除的 VMware 运行日志和临时文件
- [ ] 使用分卷压缩并记录压缩算法、分卷大小与解压命令
- [ ] 明确压缩包大小、解压后大小和所需临时空间
- [ ] 提供至少两个可长期维护的下载源，或说明镜像链接有效期
- [ ] 对压缩包和解压后的关键文件分别发布校验值

发布后发现凭据、私钥或设计数据泄露时，应立即下线镜像、吊销凭据，并按 [SECURITY.md](../SECURITY.md) 处理，不要只删除 GitHub 页面上的链接。
